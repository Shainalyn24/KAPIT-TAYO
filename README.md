# KAPIT-TAYO

**About the project**
Kapit Tayo ("let us hold on to each other") is our midterm project for Gender & Society. The assignment asked for a functional, responsive and interactive website that promotes gender awareness, equality, inclusion, empowerment and social responsibility, built around one gender-related issue.
We chose gender-based sexual harassment in the Philippines: catcalling, groping and unwanted messages on the street, online, at school and at work. The site explains that these acts are crimes under the Safe Spaces Act (RA 11313), shows how common they are, and helps visitors find safe next steps. It is written in short, plain sentences so that students and families can use it.
